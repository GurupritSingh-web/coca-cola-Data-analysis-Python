#Coca-Cola Financial Data Analysis

#Overview
This project analyzes Coca-Cola's financial data from FY'09 to FY'18 using Python and Pandas. The project focuses on data cleaning, data analysis, financial trends, and data visualization.

#Objectives

* Clean and prepare financial data for analysis
* Handle missing and unnecessary data
* Convert financial values into appropriate data types
* Analyze revenue and profitability trends
* Calculate revenue growth and CAGR
* Analyze operating and net profit margins
* Analyze operating cash flow
* Identify important financial trends and insights
* Present findings through visualizations

#Dataset

The dataset contains Coca-Cola's financial information across FY'09 to FY'18, covering areas including:

* Revenue
* Operating income
* Net income
* Operating expenses
* Assets and liabilities
* Cash flows
* Investments
* Equity

#Tools I Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

#Data Cleaning

The dataset was cleaned before analysis by:

* Removing unnecessary rows
* Handling missing values
* Converting financial columns to appropriate numeric data types
* Checking the structure and data types of the dataset
* Resetting the DataFrame index after cleaning

#Analysis Performed

The analysis includes:

* Revenue growth analysis
* Revenue CAGR
* Operating margin analysis
* Net profit margin analysis
* Cost of goods sold analysis
* Financial trend analysis

#Visualizations

The project includes visualizations showing important financial trends across FY'09 to FY'18.
